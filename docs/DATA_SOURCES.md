# 数据源与降级语义

## 腾讯行情

当前适配器为 `tencent-qt`，批量请求 `qt.gtimg.cn`。解析后的标准字段包括：

- 股票代码和数据源当前名称；
- 现价、昨收、今开、最高和最低；
- 涨跌幅、换手率、振幅、成交量和成交额；
- PE、PB；
- 行情交易时间和本机抓取时间。

腾讯当前返回的时间按 `Asia/Shanghai` 解析，不会伪装为 UTC。服务端名称优先于预置名称，因此公司更名后界面可以显示新名称，代码仍保持稳定。

## 数据状态

- `ok`：当前消费方所需字段完整；
- `degraded`：有真实行情，但某些增强字段缺失；
- `error`：没有可用的最新价或数据源请求失败。

目前单独使用腾讯行情时，主力净流入比、扣非质量和 MA5/10/20 缺失，所以全池结果会显示 `degraded`。评分时这些维度取中性 0 分，不生成随机数或猜测值。

## 缓存

每次扫描会按“股票代码 + 数据源 + 交易时间”写入 SQLite。重复扫描同一行情时更新抓取时间和载荷，不重复堆积记录。
