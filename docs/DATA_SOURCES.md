# 数据源与降级语义

## 腾讯行情

当前适配器为 `tencent-qt`，批量请求 `qt.gtimg.cn`。解析后的标准字段包括：

- 股票代码和数据源当前名称；
- 现价、昨收、今开、最高和最低；
- 涨跌幅、换手率、振幅、成交量和成交额；
- PE、PB；
- 行情交易时间和本机抓取时间。

腾讯当前返回的时间按 `Asia/Shanghai` 解析，不会伪装为 UTC。服务端名称优先于预置名称，因此公司更名后界面可以显示新名称，代码仍保持稳定。

## 腾讯前复权日线

`tencent-qfq-day` 为每只股票获取最近 30 条前复权日线，至少有 20 条有效收盘价时计算 MA5、MA10 和 MA20。66 只固定股票通过有限并发获取，单只日线失败不会拖垮整次扫描。

个股深研会单独获取最近 252 条前复权日线，计算 MA5/10/20/60、MACD、RSI14、20 日支撑压力、52 周高低点和近 5 日量比。深研同时并行请求东方财富公开接口：资金流日线、最新财务报告、行业涨幅横截面和相关新闻搜索。四类结果都会携带 `source`、`fetched_at`、`status` 和错误原因，并保存到分析快照。

知行指数会在上述事实之上计算十个可解释因子，并始终按十个因子平均为 0–100 分；不可用因子按中性 50 计入，同时输出 `factor_coverage` 和 `zhixing_confidence`，避免数据源偶发失败改变分母。相对强度使用 `sh000001` 的 20 日收益作基准，周线由日线按 ISO 周聚合。参考池只作为个人偏好加分，不限制全市场查询。每份报告还保存算法版本和规则指纹。

## AKShare 可选备用源

`requirements-optional.txt` 提供 AKShare 安装入口。默认仍优先使用腾讯；当最新价、涨跌幅、PE/PB 等核心字段缺失，或前复权日线请求失败时，才调用 AKShare 东方财富现货/日线接口。AKShare 不可用时不会阻塞主流程，报告和扫描继续按原有降级语义返回。

## 数据状态

- `ok`：当前消费方所需字段完整；
- `degraded`：有真实行情，但某些增强字段缺失；
- `stale`：本次请求失败，使用 SQLite 最近一次成功快照，并显示数据年龄；
- `error`：没有可用的最新价或数据源请求失败。

报告拆分为核心行情状态、增强数据状态和旧版火箭评分状态。全池扫描仍只依赖腾讯行情和日线；资金流、财务、行业和新闻属于个股深研扩展源，不会拖慢或改变全池扫描。增强源请求会自动重试一次，成功结果写入 `analysis_source_cache`；失败时优先回退到最近成功快照，不使用默认值填充。

## 缓存

每次扫描会按“股票代码 + 数据源 + 交易时间”写入 SQLite，并保存一份扫描运行记录及逐只结果。重复扫描同一行情时更新抓取时间和载荷，不重复堆积记录。加入预选股后会建立 1、5、20 个交易日的待核验记录；后续扫描或调用核验接口时，使用目标交易日之后的第一条有效快照计算表现。
