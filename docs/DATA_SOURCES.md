# 数据源与降级语义

## 腾讯行情

当前适配器为 `tencent-qt`，批量请求 `qt.gtimg.cn`。解析后的标准字段包括：

- 股票代码和数据源当前名称；
- 现价、昨收、今开、最高和最低；
- 涨跌幅、换手率、振幅、成交量和成交额；
- PE、PB；
- 行情交易时间和本机抓取时间。

腾讯当前返回的时间按 `Asia/Shanghai` 解析，不会伪装为 UTC。服务端名称优先于预置名称，因此公司更名后界面可以显示新名称，代码仍保持稳定。

## 腾讯前复权日线

`tencent-qfq-day` 为每只股票获取最近 30 条前复权日线，至少有 20 条有效收盘价时计算 MA5、MA10 和 MA20。66 只固定股票通过有限并发获取，单只日线失败不会拖垮整次扫描。

## 数据状态

- `ok`：当前消费方所需字段完整；
- `degraded`：有真实行情，但某些增强字段缺失；
- `error`：没有可用的最新价或数据源请求失败。

实时行情和日线合并后，主力净流入比和扣非质量仍缺失，所以全池结果依然会显示 `degraded`。评分时这两个维度取中性 0 分，不生成随机数或猜测值。

## 缓存

每次扫描会按“股票代码 + 数据源 + 交易时间”写入 SQLite，并保存一份扫描运行记录及逐只结果。重复扫描同一行情时更新抓取时间和载荷，不重复堆积记录。加入预选股后会建立 1、5、20 个交易日的待核验记录；后续扫描或调用核验接口时，使用目标交易日之后的第一条有效快照计算表现。
