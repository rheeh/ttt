# A股 K线训练

新增侧栏「K线训练」，也可直接打开 <http://127.0.0.1:5173/#training>。设计参考 [K线道场的历史盲练流程](https://xiaobang666.com/kline/train)，代码、界面和训练引擎独立实现，未复制第三方题库或素材。

## 使用流程

1. 选择主板参考池或我的主板自选，选择 20／40／60 个交易日。
2. 随机抽取一只股票的一段真实历史，先展示 60 根日线，隐藏股票名称、代码和真实日期。
3. 可切换日／周线与 MA5／10／20，记录判断理由，选择全部／二分之一／四分之一资金或持仓。
4. 买入、卖出、观望均推进一个交易日；按照下一交易日开盘价模拟成交。
5. 自动保存每次决策。刷新、切换页面或重启 API 后，可继续唯一进行中的训练。
6. 走完推演后揭晓股票与训练日期，展示资金曲线、买入持有基准、超额百分点、收盘权益最大回撤、费用与逐笔记录。
7. 可以提前结束并揭晓；提前结束不可继续，保留复盘，不计入完整训练统计。

## 已实现范围

- 沪深主板：`sh600/601/603/605` 与 `sz000/001/002/003`，排除非股票资产和名称包含 ST／退的标的。
- 项目现有参考池共 66 只主板股票（配置改变时界面数量随之变化），不是全 A 市场或当前沪深 300 成分。
- 我的主板自选使用当前本机持久化自选列表，适用同样的主板过滤。
- 周线只聚合已经揭示的日线，不补全尚未知晓的周内行情。操作始终按交易日推进。
- 最近 30 局记录可重新打开，完整训练的统计覆盖本机全部已完成训练。
- 规则统计复盘，不调用语言模型，不设置公众排行榜或跨局本金生涯模式。

## 成交和绩效口径

本金固定 100,000 元，只做多，不融资。买入数量为 100 股整数倍，买入比例应用于可用资金，佣金包含在预算内；卖出比例应用于已持有股数，并向下取整至 100 股。单次操作完成后才展示新日线，因此下一次卖出最早在再下一交易日开盘，符合 T+1。

固定模拟费率：双边佣金 0.03%，每笔最低 5 元；卖出另计 0.05%。佣金、卖出税费各自按四舍五入取到分再相加。未单列过户费、未模拟滑点和历史费率变化。这些是本模块的简化参数，不代表用户券商真实费率。

价格使用前复权日线，是训练价，不是历史当时的真实委托价格。零成交量不成交；单一价上涨日不买、单一价下跌日不卖，作保守成交判断。未取得逐日 ST 状态、官方涨跌停价、盘口和排队数据，不能完整复现涨跌停、竞价、流动性限制或除权派息；也不能把该模块当成严格历史交易回测。

买入持有基准使用相同本金、整手与佣金，于训练期首个可买入开盘进入并持有。当前权益 = 可用现金 + 股数 × 最新已揭示收盘价。收益率对照初始本金；超额为本局收益率减基准收益率，单位为百分点；最大回撤对初始本金及每日收盘权益的历史最高点计算，不包含日内回撤。

结束仅按收盘价估值，不强制平仓，不扣除假想卖出费用。无成交的局也可以完成，盈利局定义为本局收益大于 0。提前结束不进入胜率、平均收益或最佳收益。

参考规则：[上交所交易规则（2026 年修订）](https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml)；[证券交易印花税减半征收公告](https://fgk.chinatax.gov.cn/zcfgk/c102416/c5211343/content.html)。

## 历史来源、缓存和盲练边界

使用项目已有腾讯行情来源，由训练专用适配器请求 `web.ifzq.gtimg.cn/appstock/app/fqkline/get`，参数为 640 根 `qfq` 日线。只接受显式 `qfqday`，不静默使用未复权数据。验证日期严格递增、OHLC 关系、有限正数价格与非负成交量，并排除本机当天和未来的未完成日线。

每局固定保存抽取的行情片段，后续推进不再依赖网络。开局优先复用抽中标的的本地历史；没有时最多尝试 4 只股票的在线请求，再尝试题库内其余本地缓存。历史不足时返回 503，不生成伪行情。缓存属于历史题库，不自动追求最新行情，复盘中展示采集时间和缓存状态。

题库受既有选样与存续偏差影响，名称来自参考池／自选配置，可能不是该历史时点的名称。腾讯数据也不提供完整的可交易状态。历史前复权本身使用复权信息，因此此处“盲练”指隐藏身份、时间与未推进的价格路径，不宣称信息论意义的严格双盲回测。

完整行情、股票身份和交易日期留在后端。进行中的 API 只返回截至当前进度的 OHLCV、序号、匿名周分组、可见指标所需数据、账户和已执行记录；结束后才返回股票、日期、采集时间。没有提供跳日、修改现金或任意写入行情的 API。用户本人仍可访问本机 SQLite，此措施防止前端提前加载答案，不是针对本机管理员的安全隔离。

## 代码和存储

- `apps/desktop/src/KlineTraining.tsx`：训练大厅、交易面板、复盘和历史。
- `apps/desktop/src/TrainingChart.tsx`：日周 K 线、成交量、均线、买卖标记和权益曲线。
- `apps/desktop/src/trainingApi.ts`、`training.css`：独立接口类型及模块样式。
- `services/desktop-api/app/training/service.py`：行情适配、撮合、统计、持久化及对外脱敏。
- `services/desktop-api/app/training/router.py`：参数校验与 API 路由。
- `tests/test_training.py`：隔离临时数据库的确定性测试。

沿用 `STOCK_RESEARCH_DATA_DIR` 下的 `research.sqlite3`，新增 `kline_history`（真实历史缓存）和 `kline_sessions`（每局固定行情、状态、资金、决策和权益序列）。以独立表增量创建，不修改原研究记录。每次写入在 SQLite `BEGIN IMMEDIATE` 事务中检查 `revision`，并用唯一索引限制仅一个进行中的训练，防止双击、网络重试和并发窗口重复成交。

| 接口 | 用途 |
|---|---|
| `GET /api/training` | 题库数量、当前训练、统计和最近记录 |
| `POST /api/training/sessions` | `{pool: reference/watchlist, steps: 20/40/60}` 开局 |
| `GET /api/training/sessions/{id}` | 当前已揭示状态或已结束复盘 |
| `POST /api/training/sessions/{id}/actions` | `{revision, action: buy/sell/hold/finish, fraction: .25/.5/1, note}` |

不存在记录返回 404；无效参数返回 422；陈旧 revision、已有进行中训练或已结束返回 409；行情不可用返回 503。页面显示原因并提供刷新，失败请求不会默默重复下单。

## 验证

`./scripts/verify.sh` 运行全套 Python 测试、ESLint 和生产构建。新增测试覆盖未来行情不下发、下一开盘撮合、整手与费用、并发 revision、重启恢复、完整结算、提前结束、单一价及零量限制、现金不足、缓存离线回退、题库筛选、错误数据、权益回撤和 HTTP 校验。

浏览器验收使用真实腾讯数据，通过 Playwright 操作实际页面；截图保存在忽略提交的 `output/playwright/`。手动验收建议：开局 → 半仓买入 → 观望 → 卖出 → 刷新恢复 → 日周切换 → 结束复盘 → 历史重开；同时在桌面与 375px 手机尺寸检查页面无整体横向溢出，手机图表可内部横向滑动并自动跟随最新 K 线。

2026-09-05 验证结果：当前工作区 63 项 Python 测试通过（新增 14 项）；仅本次改动导出的独立提交快照 57 项测试通过，ESLint 和 Vite 生产构建通过。真实腾讯行情完成 20 日浏览器训练，涵盖半仓买入、观望、卖出、刷新恢复、日周切换、逐步响应无未来数据、自动揭晓和历史重开。1440px 桌面、375px 竖屏与 812px 横屏检查通过；375px 下页面宽度为 375px。验收训练记录在导出本地验收材料后移除，历史行情缓存保留供用户训练。
