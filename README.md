# 知行股研

知行股研是一个面向 A 股市场的研究工作台，将股票筛选、规则评分、技术分析、行业观察与研究复盘整合为连续的工作流程。通过可解释的评分因子、带来源的行情数据和可回看的研究快照，帮助组织信息、比较标的，并跟踪研究结论的后续表现。

[在线体验](https://rheeh.github.io/ttt/) · [主页演示](https://rheeh.github.io/projects/zhixing/) · [功能实现说明](docs/IMPLEMENTATION.md) · [数据来源](docs/DATA_SOURCES.md)

## 功能概览

### 个股研究

- 按代码或名称搜索股票，管理自选列表和最近研究记录。
- 展示前复权 K 线、移动均线、MACD、RSI、支撑压力与价格区间。
- 结合 0–100 知行指数、十因子评分、六维雷达和日周线共振，呈现多空证据与待核实因素。
- 汇总资金流、财务增速、行业表现和相关新闻，显示来源、抓取时间、字段缺失与降级状态。
- 手动保存研究快照，按股票归并时间线，并根据交易日与结论指纹去重。

### 参考池与规则评分

- 提供可选的 66 只 A 股与 11 只 ETF 参考池；参考池不限制全市场搜索范围。
- 使用版本化策略 JSON 和确定性规则引擎，输出七个维度的分数、触发原因、总分及 S/A/B/C 等级。
- 支持行情批量扫描、候选筛选与轮动池整理。轮动池最多保留 25 只股票，同一板块最多 3 只。
- 候选记录保留策略版本和规则指纹，便于追踪评分依据。

七个规则维度为估值、价量、板块、资金、趋势、风险和扣非质量。默认等级阈值如下：

| 等级 | 规则累计分 |
| --- | --- |
| S | ≥ 22 |
| A | ≥ 14 且 < 22 |
| B | ≥ 5 且 < 14 |
| C | < 5 |

规则累计分不是百分制，与个股深研中的知行指数分别计算。评分用于整理规则命中情况，不等同于概率预测。

### 股票对比与板块观察

- 同时分析 2–3 只股票，以归一化走势和一致的指标口径进行比较。
- 板块雷达展示行业涨幅、成分覆盖和数据可用状态，辅助观察行业变化。
- 对数据不足的指标明确显示边界，保留核心结果与增强数据的状态区别。

### 信号核验与 K 线训练

- 跟踪候选信号在 1、5、20 个实际交易日后的表现，展示均值、中位数，以及数据可用时相对沪深 300 的超额收益。
- 使用历史日线开展随机盲练，支持 20、40、60 个交易日推演、模拟买卖、自动续练和结算复盘。
- 训练历史数据可通过缓存复用；具体成交规则与数据边界见 [K 线训练说明](docs/KLINE_TRAINING.md)。

## 在线演示

静态演示打开即可使用，支持以下流程：

1. 在参考池中按名称、行业、等级或类型筛选样本，加入自选。
2. 进入个股研究，切换 60 / 120 日 K 线，查看评分明细和数据依据。
3. 写下研究笔记、保存快照，再从研究记录中回看。
4. 选择 2–3 个样本，比较归一化走势与各维度分数。

演示中的标的名称、代码、行情和走势均为合成数据；评分由项目实际使用的 `StrategyEngine` 生成。自选和快照保存在当前浏览器中。完整版的数据接入、板块雷达、信号核验和 K 线训练需在本地运行。

演示源码位于 [`demo/`](demo/)，数据生成与发布方式见 [静态演示说明](docs/STATIC_DEMO.md)。

## 技术架构

| 层级 | 技术与职责 |
| --- | --- |
| 前端 | React 19、TypeScript、Vite；研究工作台、图表与交互 |
| API | FastAPI、Pydantic；分析任务、候选管理与训练接口 |
| 分析引擎 | Python；规则评分、技术指标、研究诊断与表现核验 |
| 数据适配 | 腾讯行情与日线、东方财富增强数据，以及可选 AKShare 备用源 |
| 存储 | SQLite；自选、扫描记录、行情缓存、研究快照与训练记录 |
| 配置 | JSON 策略规范、可选股票 / ETF 参考池 |

```text
apps/desktop/                 React 研究工作台
services/desktop-api/app/      本地 API、行情适配与分析引擎
packages/strategy-spec/        策略配置与 JSON Schema
packages/stock-presets/        可选参考池
demo/                         无后端静态交互演示
tests/                        后端与评分测试
scripts/                      初始化、启动、验证与演示工具
docs/                         功能说明与数据边界
```

## 本地运行

需要 Python 3.11+ 和 Node.js 22.13+。初始化脚本默认使用 `python3.12`：

```bash
git clone https://github.com/rheeh/ttt.git
cd ttt
./scripts/bootstrap.sh
./scripts/dev.sh
```

如需指定 Python：

```bash
PYTHON_BIN=python3.11 ./scripts/bootstrap.sh
```

- 研究工作台：[http://127.0.0.1:5173](http://127.0.0.1:5173)
- API 文档：[http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs)

可选安装 AKShare 备用源：

```bash
.venv/bin/python -m pip install -r requirements-optional.txt
```

运行项目验证：

```bash
./scripts/verify.sh
```

仅预览静态演示：

```bash
python3 -m http.server 4178 --directory demo
# 打开 http://localhost:4178
```

## 数据与存储

行情请求失败时，系统会按适配器配置重试、切换备用源或使用最近成功的缓存，并在界面中标明缓存年龄与降级原因。缺失字段、核心评分和增强评分分别记录，避免将数据不足呈现为完整分析。

数据库默认保存在当前用户的本地应用数据目录，不随仓库提交。后端默认监听 `127.0.0.1`，提供研究、模拟与复盘功能。

更多信息见 [数据来源与限制](docs/DATA_SOURCES.md)、[实现说明](docs/IMPLEMENTATION.md) 和 [第三方声明](THIRD_PARTY_NOTICES.md)。
