# 知行股研

一个独立开发、仅限个人使用的 A 股研究工具。它保留固定观察池、S/A/B/C 经验评分、轮动加分和个人价格区间，但不连接券商、不执行交易。

当前已完成第一个纵向闭环：

- 可版本化的个人策略 JSON；
- 确定性评分引擎，输出维度分、总分、等级和过滤原因；
- SQLite 长期保存预选股；
- FastAPI 本地 API，只监听 `127.0.0.1`；
- React 桌面工作台原型，支持评分和加入观察。
- 完整的 66 只固定 A 股池和 11 只 ETF 池；
- 腾讯实时行情批量适配器与全池评分扫描；
- 腾讯前复权日线适配器，为全池计算 MA5/10/20；
- 行情来源、交易时间、抓取时间、缺失字段和降级状态；
- 行情快照本地缓存，数据源暂时失效后仍可保留历史。
- 扫描运行记录、25 只上限且单板块最多 3 只的轮动池；
- 扫描结果批量加入长期预选股，并自动建立 1/5/20 个交易日表现核验；
- 候选与扫描结果记录策略规则指纹，侧栏未实现模块明确标记“建设中”。

## 本地启动

需要 Python 3.11+ 和 Node.js 20+。

```bash
./scripts/bootstrap.sh
./scripts/dev.sh
```

启动后：

- 前端：<http://127.0.0.1:5173>
- API 文档：<http://127.0.0.1:8765/docs>

## 数据与安全

数据库默认保存在当前用户的本地应用数据目录，不会提交到 Git。仓库不包含 API Key，也没有券商、委托、撤单或自动下单代码。

详细评估和分期路线见 [docs/IMPLEMENTATION.md](docs/IMPLEMENTATION.md)。
数据字段和已知限制见 [docs/DATA_SOURCES.md](docs/DATA_SOURCES.md)。
